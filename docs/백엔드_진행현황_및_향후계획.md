# 백엔드 진행 현황과 검증 범위

2026-10-21 공개 포트폴리오 정리 기준. 10월 16일까지의 부동산 확장·연동 준비를 반영하고 공개 사본을 다시 빌드·검사했다. 이전 방 API 문서는 현재 V2 계약으로 갱신했다.

## 반영한 구현

- 건물·호실·공간·매물 책임 분리, 매매·전세·월세 검색과 게시 상태/버전 관리.
- 사용자 소유권, 주소 확인·위치 공개 범위·지도 조회, 관심 매물·문의와 답변.
- 사진 정확히 네 장, 중복 checksum·원본 표시 크기·사진별 보정 좌표 검증.
- 분석과 보정/재구성 Outbox, lease·고정 멱등성 키·재시도·지연 callback 보호.
- 이미지/GLB 검증·불변 완료 자산, 매물의 특정 완료 모델 선택.
- JWT/OAuth 설정 분리·내부 AI 인증·Flyway V1~V5·영속 volume·백업/격리 복원.
- 실제 로그인·팀원 PC AI용 격리 실행·양방향 SSH·준비 검사 도구. 도구 준비와 실제 연결 완료는 별개다.

## 따로 검증할 일

- 실제 Kakao 앱 설정과 본인 계정 로그인.
- 프론트 V2 요청·GLB 업로드 계약, 실제 가구 파일/브라우저 로딩.
- 팀원 PC의 코드 버전·GPU·가중치·내부키·사진 GET/callback 연결 후 새 사진 네 장 E2E.
- 방 좌표 단위·스케일과 가구 치수, 직접 움직인 가구의 실제 저장 후 위치 보존.
- 빈 최종 좌표·예외를 사용자에게 명확히 알리는 결과 품질 처리.
- 다중 인스턴스 전역 동시성·운영 부하/가용성·실행 중 GPU 장애 복구.
